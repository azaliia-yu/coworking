# Coworking Space Management App (Дипломный проект)

Веб-приложение для комплексного управления коворкингом. Сервис позволяет клиентам находить и бронировать рабочие места с интерактивной картой и онлайн-оплатой, а администраторам — гибко управлять пространством, тарифами и отслеживать аналитику.

## Технологический стек

**Backend:**
* Python / Django
* PostgreSQL (основная база данных)
* Redis (кэширование и брокер сообщений)
* Celery & Celery Beat (фоновые задачи: обработка бронирований, рассылки)
* Docker / Docker Compose (контейнеризация)

**Frontend:**
* React (JavaScript/TypeScript)
* Recharts (построение графиков и дашбордов)

---

## Основной функционал

### Для клиентов:
* **Авторизация:** Регистрация и вход по Email/паролю.
* **Поиск и карта:** Просмотр списка помещений, интерактивная карта с доступными местами, превью и галереей.
* **Бронирование:** Выбор даты/времени с автоматической проверкой доступности в реальном времени.
* **Оплата:** Расчет стоимости в зависимости от тарифа, списание средств с внутреннего баланса.
* **Личный кабинет:** История бронирований, отмена, пополнение баланса и редактирование профиля.

### Для администраторов:
* **Управление помещениями:** Создание, редактирование и загрузка плана помещения (`map_image`).
* **Управление местами:** Drag-and-drop рабочих мест на плане, настройка координат, характеристик и фото.
* **Тарифы и цены:** Управление тарифами и привязка индивидуальных цен к конкретным местам.
* **Пользователи:** Просмотр, блокировка и разблокировка аккаунтов клиентов.
* **Аналитика:** Генерация отчетов по загрузке, доходам и клиентам (экспорт в JSON/CSV), дашборд с ключевыми метриками и графиками (Recharts).
* **Настройки:** Гибкая настройка правил бронирования и рабочих часов.

## Быстрый запуск (через Docker)

Проект полностью докеризирован, для запуска вам понадобятся только установленные **Docker** и **Docker Compose**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git
   cd НАЗВАНИЕ_РЕПОЗИТОРИЯ
2. Запустите сборку и поднимите контейнеры в фоновом режиме:

bash
docker-compose up -d --build
3. Примените миграции базы данных:

bash
docker-compose exec backend python manage.py migrate
4. (Опционально) Создайте суперпользователя для доступа в админку Django:

bash
docker-compose exec backend python manage.py createsuperuser
Сервисы будут доступны по адресам:

Frontend (React): http://localhost:3000

Backend (API / Админка): http://localhost:8000

PostgreSQL: порт 5433

Redis: порт 6380
